# Kanban

Kanban-доска доступна внутри каждого проекта по адресу `/projects/<id>/kanban`.
Общая доска по всем проектам — `/kanban`.

## Возможности

- **Колонки** — настраиваемые статусы задач с цветом и порядком.
- **Задачи** — описание, приоритет, дедлайн, **несколько ответственных**, теги. Название необязательно: без него задача отображается как «Заявка #N».
- **Общая доска** — объединяет колонки всех проектов. Если перенести задачу в общую колонку, которой ещё нет в её проекте, эта колонка создаётся в проекте с общими цветом и порядком.
- **Закрытие задач** — чекбокс «Закрыто» в форме задачи. Закрытая задача становится неактивной: сбрасывается дедлайн, задача уходит вниз колонки и в конец списков (сортировка по активности и дате создания). При переоткрытии задача возвращается в начало колонки.
- **Вложения** — ссылки, файлы, git-репозитории. У вложений-ссылок есть зелёная кнопка копирования ссылки. Предпросмотр файлов и редактирование в Collabora Online открываются в новой вкладке.
- **Drag-and-drop** — перемещение задач между колонками.
- **Фильтры** — по списку, приоритету, ответственным, тегу, дедлайну и дате создания. Списки и варианты тегов загружаются по задачам; ToDo-список и учет времени предлагают теги в поле ввода, Kanban показывает их в списке.
- **Назначить себя** — в форме задачи есть кнопка «Назначить себя». На сервере она использует email подтверждённого пользователя; локально — исполнителя, заданного через `MCP_LOCAL_ASSIGNEE_NAME` и найденного в справочнике ответственных.
- **Импорт/экспорт** — JSON для переноса доски между проектами.
- **Прямые ссылки** — `/projects/<id>/kanban?task=<task_id>` подсвечивает задачу на доске.

## Создание задачи из колонки

Кнопка «Добавить задачу» внизу каждой колонки открывает форму с подставленным статусом этой колонки:

- В kanban проекта проект уже известен — статус колонки сразу выбран в форме.
- В общем kanban (`/kanban`) проект не заполняется автоматически: выберите проект вручную, и статус подставится по имени колонки (если в проекте есть статус с таким именем).

## Список задач (ToDo-список)

Кнопка «ToDo-список» на доске открывает таблицу всех задач: `/projects/<id>/tasks` — по проекту, `/tasks` — по всем проектам.

- Все поля задачи в колонках, сортировка кликом по заголовку.
- Фильтры (оформлены как на kanban): поиск, проект, статус, приоритет, ответственные, список, состояние (открыта/закрыта), теги.
- Таблица на всю ширину экрана, горизонтальная прокрутка сверху и снизу; фиксированная высота строк — длинное описание обрезается многоточием.
- **Сохранить список** — выгрузка отфильтрованных задач в текстовый вид (копирование или скачивание `.txt`): выбор колонок и формата — нумерованный список (по умолчанию), чек-лист ToDo, Markdown-таблица, одна строка — одна задача. Колонки, по которым выставлены фильтры, снимаются с выбора автоматически.
- **Экспорт в JSON/CSV** — включает название проекта; даты и метка времени в имени файла — по московскому времени (UTC+3).
- **Диаграмма Ганта** — переключатель в правом верхнем углу переключает таблицу задач в диаграмму Ганта. Отображаются задачи с учётом текущих фильтров, дедлайны выделяются цветом по приоритету, текущий день подсвечивается. Есть кнопки быстрой навигации: «Начало», «Сегодня», «Окончание», чекбокс «Скрыть без дедлайна» и выгрузка диаграммы в `.xlsx`.
- **Учет времени** — отдельная страница с таблицей плановой оценки, фактической работы, тестирования, общего факта и отклонения от плана. Оценка задаётся в минутах в форме задачи.

## Диаграмма Ганта

Диаграмма Ганта доступна на странице списка задач по кнопке «Гант». Перед ней расположена кнопка «Учет времени», после неё — «Импорт задач».

- Левая часть показывает задачи с колонками: `#`, `Название`, `Исполнитель`, `Начало`, `Конец`, `Длит.`, `План / факт`.
- Правая часть — шкала дней от минимальной даты (создание задачи) до максимального дедлайна с запасом в несколько дней.
- Цветная заливка соответствует приоритету задачи (зелёный / жёлтый / красный) или серому для закрытых.
- Текущий день выделен полупрозрачным серым фоном; цвет задачи отображается поверх этого фона.
- Левая панель адаптируется при сужении экрана: колонки `Название` и `Исполнитель` сужаются, длинный текст обрезается многоточием.
- Кнопки «Начало», «Сегодня», «Окончание» прокручивают timeline к соответствующей позиции.
- Чекбокс «Скрыть без дедлайна» убирает из диаграммы задачи без дедлайна.
- Кнопка **XLSX** выгружает текущую диаграмму (с учётом фильтров и чекбокса «Скрыть без дедлайна») в Excel-файл с двумя листами: визуальная диаграмма и таблица задач.

## Учет времени задач

Страница доступна из ToDo-списка по кнопке «Учет времени»: `/tasks/time` — по всем проектам, `/projects/<id>/tasks/time` — по проекту.

- В таблице показываются план, активное время этапов «В работе» и «Тестирование», факт и отклонение от плана.
- Отклонение окрашивается зелёным, если фактическое время меньше планового, и красным, если больше; равные значения остаются нейтральными.
- В таблице по умолчанию показываются только задачи с плановой оценкой или фактическими сессиями.
- Фильтры по проекту, статусу, приоритету, ответственному, списку, тегам, дате создания и дедлайну находятся в сворачиваемой панели, которая изначально скрыта. Списки значений для проектов, статусов, приоритетов, ответственных, списков и тегов заполняются по задачам автоматически; для тегов доступны подсказки. Даты создания фильтруются интервалом «с/по», дедлайн — значением «до».
- Закрытые задачи в таблицу учёта времени не попадают.
- Нажатие на название задачи открывает форму для ручного изменения плана, времени работы, тестирования и факта. При изменении времени работы или тестирования факт пересчитывается по этапам.
- Кнопка **XLSX** выгружает отображаемые строки с учётом активных фильтров и итогами таблицы. Колонка «Факт» и строка «Итого» имеют светлую заливку.
- Время отображается в днях, часах и минутах. Итоги пересчитываются по текущему набору задач.
- Фактическое время складывается из активных сессий агента. Паузы и время между сессиями не учитываются.
- Сессии ведутся отдельно по агентам и этапам. Агент берёт карточку в «В работе» и запускает рабочий интервал. После реализации переводит карточку в «Тестирование»: рабочий интервал закрывается, запускается интервал собственного тестирования.
- При любой остановке работы или тестирования, ожидании ответа пользователя и перед передачей результата агент приостанавливает сессию через MCP независимо от статуса. При продолжении того же этапа запускается новая сессия; накопленное время сохраняется.
- После собственных проверок агент останавливает таймер и оставляет карточку в «Тестировании». Если пользователь поручает доработку, агент возвращает её в «В работе» и запускает новый рабочий интервал.
- Переключение агента на другую задачу автоматически закрывает его предыдущую сессию. Переход задачи в другой статус также закрывает активные интервалы; изменение описания, результата, исполнителей или повторная передача текущего статуса не возобновляют таймер.
- После перезапуска ARMory незавершённые интервалы закрываются на время запуска приложения.

## Импорт задач

Кнопка «Импорт задач» на странице списка задач создаёт задачи из текстового списка:

- Каждый импортированный список помечается своим названием (колонка «Список») — по нему можно фильтровать и сортировать.
- Текст каждого пункта попадает в «Описание» задачи, название не заполняется.
- Доступны массовые настройки (дедлайн, приоритет, ответственные, теги) и общие вложения — они применяются к каждой задаче списка.

## Прямые ссылки на задачи

Чтобы поделиться конкретной задачей, скопируй ссылку вида:

```text
/projects/<project-id>/kanban?task=<task-id>
```

При открытии такой ссылки задача подсвечивается на доске. Первый клик по подсвеченной карточке только снимает подсветку; повторный клик открывает задачу как обычно.
