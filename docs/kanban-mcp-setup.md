# Настройка Kimi Code для работы с kanban ARMory

Этот мануал поможет настроить Kimi Code CLI так, чтобы можно было работать с задачами kanban ARMory (`https://armory.team-73.ru`) из любой папки на своём компьютере.

## Что понадобится

- Установленный [Kimi Code CLI](https://www.kimi.com/code/).
- API-ключ для подключения к ARMory. Получите его у администратора или сгенерируйте сами на сервере командой:

```bash
openssl rand -hex 32
```

## Шаг 1. Создать файл подключения

Создай файл `~/.kimi-code/mcp.json` со следующим содержимым:

```json
{
  "mcpServers": {
    "armory": {
      "url": "https://armory.team-73.ru/mcp",
      "headers": {
        "X-MCP-API-Key": "YOUR_MCP_API_KEY"
      }
    }
  }
}
```

Вместо `YOUR_MCP_API_KEY` вставь настоящий ключ.

> **Важно:** `~` — это твоя домашняя папка. На Linux/macOS это `/home/имя_пользователя`, на Windows — `C:\Users\имя_пользователя`.

## Шаг 2. Создать инструкцию для Kimi

Создай папку и скопируй в неё готовый skill из репозитория ARMory:

```bash
mkdir -p ~/.kimi-code/skills/kanban
cp /home/user_name/ARMory/.kimi-code/skills/kanban/SKILL.md ~/.kimi-code/skills/kanban/SKILL.md
```

Если у тебя нет локальной копии репозитория ARMory, попроси администратора скинуть файл `SKILL.md` и положи его в `~/.kimi-code/skills/kanban/SKILL.md`.

## Шаг 3. Перезапустить Kimi

Kimi подключает MCP-серверы только при запуске. После создания файлов нужно выйти и зайти заново:

```bash
exit
kimi
```

## Шаг 4. Проверить подключение

Внутри Kimi выполни команду:

```
/mcp
```

Если всё настроено правильно, Kimi покажет список подключённых MCP-серверов, в том числе `armory`.

## Шаг 5. Начать работать с задачами

Теперь можно работать с задачами ARMory из любой папки. Примеры фраз:

```
Возьми в работу задачу #39
```

```
https://armory.team-73.ru/projects/2/kanban?task=39
```

```
Покажи задачу #39
```

```
Переведи #39 в статус "Тестирование"
```

```
Обнови #39 результат "Исправлено отображение дедлайна"
```

```
Закрой #39 с результатом "Реализовано в PR #123"
```

## Если что-то не работает

1. Проверь, что файл `~/.kimi-code/mcp.json` существует и в нём правильный ключ.
2. Проверь, что файл `~/.kimi-code/skills/kanban/SKILL.md` существует.
3. Убедись, что Kimi был перезапущен после создания файлов.
4. Выполни в Kimi команду `/mcp` и посмотри, есть ли сервер `armory` в списке.
5. Если сервера нет, проверь вывод команды `/mcp` на наличие ошибок подключения.

## Что делает каждый файл

- `~/.kimi-code/mcp.json` — говорит Kimi, как подключиться к серверу ARMory и какие инструменты использовать.
- `~/.kimi-code/skills/kanban/SKILL.md` — учит Kimi понимать ссылки и номера задач, не закрывать задачи без разрешения и правильно оформлять результат работы.
