# Дела и ежедневная сводка

Раздел `/affairs` предназначен для коротких личных и общих заметок, которые не требуют полноценной Kanban-задачи. Он доступен при `PERSONAL_NOTES_ENABLED=true`.

## Возможности

- личные записи, видимые только владельцу;
- общие записи для пользователей ARMory;
- привязка записи к проекту;
- описание и срок выполнения;
- отметка о выполнении;
- публикация общей записи в ежедневной сводке;
- скрытие сводки пользователем до следующего дня.

Идентификатор пользователя берётся из email, переданного шлюзом авторизации. Постоянные пользовательские состояния хранятся на сервере.

## Отличие от задач

Дело — компактная запись для личного планирования или информационной ленты. Задача содержит статус Kanban, приоритет, ответственных, вложения и историю перемещений. Для контролируемой работы по процессу используйте задачу.

## Настройка

```dotenv
PERSONAL_NOTES_ENABLED=true
```

После изменения переменной перезапустите приложение. Когда функция отключена, страница `/affairs` возвращает `404`, а пункт меню скрыт.

## API

Маршруты начинаются с `/api/affairs`: доступны список, создание, обновление, удаление, обзор и управление ежедневной сводкой.
